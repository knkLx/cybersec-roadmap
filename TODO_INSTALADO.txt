═══════════════════════════════════════════════════════════════
  HERRAMIENTA 1: PENTFLOW
═══════════════════════════════════════════════════════════════

Ubicación: ~/pentflow/

QUÉ HACE:
  - Escanea targets automáticamente
  - Encuentra vulnerabilidades
  - Genera reportes profesionales (Markdown + HTML)
  - Integra Nuclei (10,000+ templates)
  - Exporta a GitHub

CÓMO USAR:

  # Scan completo (recomendado)
  cd ~/pentflow
  python3 main.py https://target.com

  # Solo recon
  python3 main.py https://target.com -p recon

  # Solo scanning
  python3 main.py https://target.com -p scan

  # Solo exploit
  python3 main.py https://target.com -p exploit

  # Solo reporte
  python3 main.py https://target.com -p report

  # Con Nuclei
  python3 main.py https://target.com --nuclei

  # Nuclei con tags específicos
  python3 main.py https://target.com --nuclei --nuclei-tags cve,xss,sqli

  # Solo critical y high
  python3 main.py https://target.com --nuclei --nuclei-severity high,critical

  # Template específico
  python3 main.py https://target.com --nuclei --nuclei-template ~/nuclei-templates/http/cves/

  # Modo interactivo
  python3 main.py -i

  # Ver sesiones
  python3 main.py --list

  # Reanudar sesión
  python3 main.py https://target.com -s target.com_20260725_XXXXXX

  # Exportar a GitHub
  python3 main.py --export <session_id>

  # A través de Tor
  ~/pentflow/pentflow-tor https://target.com

QUÉ ESCANEA:
  FASE 1 - RECON:
    - Subdomains (crt.sh, AlienVault, ThreatCrowd, DNS brute)
    - DNS (zone transfer, wildcard)
    - Puertos (30+ comunes, async)
    - Tecnologías (20+ firmas)
    - Endpoints (40+ paths comunes)

  FASE 2 - SCAN:
    - Headers de seguridad (7 headers)
    - Info disclosure (20+ paths sensibles)
    - CORS misconfiguration
    - Clickjacking
    - Open redirect
    - Endpoints sensibles
    - Nuclei (10,000+ templates)

  FASE 3 - EXPLOIT:
    - XSS testing (reflected, stored indicators)
    - SQL injection (error-based, time-based, content-based)

  FASE 4 - REPORTE:
    - Markdown con severidades, CWE, evidencia
    - HTML con tema oscuro profesional
    - Export a GitHub

DÓNDE SE GUARDAN LOS REPORTES:
  ~/pentflow/reports/
    report_target.com_YYYYMMDD_HHMMSS.md
    report_target.com_YYYYMMDD_HHMMSS.html

DÓNDE SE GUARDAN LAS SESIONES:
  ~/pentflow/sessions/
    target.com_YYYYMMDD_HHMMSS.json

USAR TOR CON CUALQUIER COMANDO:
  torsocks python3 main.py target.com
  torsocks curl https://target.com
  proxychains4 nmap -sT target.com

CAMBIAR IP:
  killall tor && tor &

CONFIGURACIÓN:
  ~/.tor/torrc
  - SocksPort 9050
  - ExitNodes {es},{fr},{de},{nl},{ro}
  - CookieAuthentication 1

═══════════════════════════════════════════════════════════════
  SEGURIDAD: SHODAN (BÚSQUEDA IoT)
═══════════════════════════════════════════════════════════════

INSTALACIÓN:
  pip install shodan (ya hecho)

CONFIGURAR:
  1. Crear cuenta en shodan.io
  2. Obtener API key (gratis)
  3. shodan init TU_API_KEY

USAR:
  # Buscar servidores con screenshots
  shodan search "has_screenshot:true port:443" --limit 10

  # Buscar cámaras RTSP
  shodan search "port:554 has_screenshot:true" --limit 20

  # Buscar en España
  shodan search "country:ES port:22" --limit 10

  # Info de un host
  shodan host 8.8.8.8

  # Desde Python
  import shodan
  api = shodan.Shodan('TU_API_KEY')
  results = api.search('port:22 country:ES')

═══════════════════════════════════════════════════════════════
  SEGURIDAD: FIREWALL (UFW)
═══════════════════════════════════════════════════════════════

CONFIGURAR:
  sudo ufw enable
  sudo ufw default deny outgoing
  sudo ufw default deny incoming
  sudo ufw allow out 443/tcp    # HTTPS
  sudo ufw allow out 53/udp     # DNS
  sudo ufw allow out 9050/tcp   # TOR
  sudo ufw status

═══════════════════════════════════════════════════════════════
  SEGURIDAD: MACCHANGER
═══════════════════════════════════════════════════════════════

INSTALACIÓN:
  sudo apt install macchanger

USAR:
  # Ver MAC actual
  macchanger -s wlan0

  # Cambiar a MAC aleatoria
  sudo ip link set wlan0 down
  sudo macchanger -r wlan0
  sudo ip link set wlan0 up

  # Volver a MAC original
  sudo ip link set wlan0 down
  sudo macchanger -p wlan0
  sudo ip link set wlan0 up
