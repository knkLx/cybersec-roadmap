  PENTFLOW — Bug Bounty Framework (v2.0)
═══════════════════════════════════════════════════════════════

Ubicación: ~/pentflow/
Ejecutar: python3 ~/pentflow/main.py target.com

Módulos (13):
  RECON:
    - subdomains.py    → Enumeración de subdominios (crtsh, alienvault, DNS)
    - ports.py         → Escaneo de puertos TCP
    - tech.py          → Detección de tecnologías
    - endpoints.py     → Descubrimiento de endpoints
    - dnsrecon.py      → Reconocimiento DNS

  SCAN:
    - headers.py       → Análisis de headers de seguridad
    - info_disclosure.py → Detección de información expuesta
    - vuln_scanner.py  → Open redirect, CORS, Clickjacking
    - nuclei_scan.py   → Escaneo con templates Nuclei
    - dir_brute.py     → Bruteforce de directorios
    - waf_detect.py    → Detección de WAF/IDS
    - scope_check.py   → Verificación de scope bug bounty

  EXPLOIT:
    - sqli_detector.py → Detección SQL Injection
    - xss_tester.py    → Prueba XSS
    - idor_tester.py   → Prueba IDOR

  REPORT:
    - generator.py     → Generación de reportes Markdown
    - github_export.py → Exportación a GitHub

Uso:
  python3 ~/pentflow/main.py example.com           # Scan completo
  python3 ~/pentflow/main.py example.com -p recon  # Solo recon
  python3 ~/pentflow/main.py --nuclei target.com   # Solo Nuclei
