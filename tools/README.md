## Inicio Rápido

```bash
# 1. Configurar seguridad
~/tools/security-setup.sh

# 2. Iniciar Tor
~/tools/start-tor.sh

# 3. Escanear con Tor
~/pentflow/pentflow-tor https://target.com

# 4. Iniciar NOVA
cd ~/nova-assistant && ./start.sh
```
